# Content authoring - modules

Use [content modules](../user/content/content-modules.md) to build your design from prepared sections, such as headers, banners, cards, and footers. Each module includes structure, styling, and default content that you can customize.

1. In the visual design space, select the **[!UICONTROL Modules]** tab if it is not visible.

   ![Module categories displayed in the visual design space](../assets/content-design-shared/content-design-modules-left-panel.png){width="500" zoomable="yes"}

1. Browse the categories, or use the search field to find a module by name.

   Expand a category to review its layout variants.

1. Drag a module variant onto the canvas.

   ![Header module displayed and dragged onto canvas](../assets/content-design-shared/content-design-modules-drag-canvas.png){width="650" zoomable="yes"}

1. Select the elements in the module to replace the default text, images, and links with your own content.

1. Use the **[!UICONTROL Settings]** and **[!UICONTROL Styles]** tabs to customize the selected component.

   ![An image component is selected in the module, with Settings displayed and the Styles tab available.](../assets/content-design-shared/content-design-modules-element-settings.png){width="650" zoomable="yes"}

   To add more content to the module, select the **[!UICONTROL Components]** tab and drag a content component into the module.
