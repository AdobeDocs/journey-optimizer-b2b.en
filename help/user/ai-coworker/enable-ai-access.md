# Enable AI access

>[!IMPORTANT]
>
>If you receive a message in the Permissions UI to inform you that your organization must first agree to additional legal terms to gain access to [!DNL Coworker] chat, contact your Adobe account team for guidance.

Use the [Permissions UI](https://experienceleague.adobe.com/en/docs/experience-platform/access-control/abac/permissions-ui/permissions){target="_blank"} to grant or revoke access to [!DNL Coworker] chat in your organization. To use [!DNL Coworker] chat, a given user must belong to a role that is configured with the _[!UICONTROL Enable AI Assistant]_ and _[!UICONTROL View Operational Insights]_ permissions.

As an administrator, you can:

* Add the **[!UICONTROL Enable AI Assistant]** permission to a given role and add a user to that role. This permission provides access to [!DNL Coworker] chat for users in your organization.

* Add the **[!UICONTROL View Operational Insights]** permission to a given role and add a user to that role. This permission allows the user to use the [!DNL Coworker] chat operational insights capabilities.

![Assign AI functional permissions](./assets/coworker-permissions.png){width="800" zoomable="yes"}

Use the Permissions UI to grant permissions to use [!DNL Coworker] chat in [!DNL Adobe Journey Optimizer B2B Edition]. For information about accessing [!DNL CX Coworker] in [!DNL Adobe Experience Platform] and other [!DNL Adobe Experience Cloud] applications, refer to the [CX Enterprise Coworker documentation](https://experienceleague.adobe.com/en/docs/coworker/content/chat/overview){target="_blank"}.

When the user has the necessary permissions, they can access [!DNL Coworker] chat by selecting the _[!DNL Coworker] chat_ icon on the top header of the application.

![[!DNL Coworker] chat icon in the application header](./assets/coworker-icon-header.png){width="800" zoomable="yes"}
